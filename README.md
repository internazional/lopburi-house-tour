# Lopburi house tour

Interactive 360 degree panoramas, room photographs and plan, rendered in Blender + Cycles.

Open [the tour](https://internazional.github.io/lopburi-house-tour/). All panorama and photo assets have been encoded as quality 92 JPEG at their original resolution for mobile loading. Full resolution PNG originals and the editable Blender scene remain local.

See tour/credits.html for the CC0 asset credits and model notes.
