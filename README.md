# Lopburi house

[Walk inside](https://internazional.github.io/lopburi-house-tour/walk/) the actual metric house model with continuous movement, mobile thumb controls, wall/furniture collision, room dimensions, a metre grid and a live plan. Eye height is 1.60 m. Doors are held open in the web copy; wall and opening positions are preserved. Lighting, reflections, plants and furniture detail are simplified for real-time rendering.

The [360 degree tour](https://internazional.github.io/lopburi-house-tour/) and [photographs](https://internazional.github.io/lopburi-house-tour/photos.html) retain the Cycles-rendered appearance. JPEG copies retain their original pixel dimensions; original PNG files and the editable Blender scene remain local.

See tour/credits.html for the CC0 asset credits and model notes. The walkthrough uses Three.js (MIT) and the Draco decoder (Apache 2.0). It runs entirely as static files, with its dependencies hosted here.
